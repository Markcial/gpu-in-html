gpu-in-html

Nine WebGPU experiments for vgpu. Open one in the browser — the page and the shader share the same measurements.

Source on GitHub

Needs WebGPU, so use Chrome or Edge. If a demo cannot get an adapter, it prints the error on the page instead of leaving a black canvas. Thumbnails are headless renders from pnpm stills, not screenshots.
